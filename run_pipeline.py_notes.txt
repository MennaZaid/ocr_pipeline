7. Command-line arguments

Inside main():

ap = argparse.ArgumentParser(...)

Then the script defines:

ap.add_argument("input")

This is mandatory.

For example:

python run_pipeline.py document.pdf

Then:

--outdir

controls where results go.

Default:

pipeline_out

Then:

--dpi

controls PDF rendering resolution.

Then:

--lang

controls language.

Then:

--prompt

controls the OCR/VLM prompt.

And these two:

--no-ain
--no-qwen

allow you to disable one branch.

For example:

python run_pipeline.py document.pdf --no-qwen

means:

AIN only

while:

python run_pipeline.py document.pdf --no-ain

means:

Qwen only

These options are defined at lines 110–119.


8. The output folders

For every document, it creates three important locations:

work_dir
ain_text_dir
qwen_text_dir

Specifically:

document_work/
document_text_ain/
document_text_qwen/

The first contains intermediate images.

The other two contain OCR results.

11. The most important part: source image

This line:

src_path = page_work_dir / f"{page_id}_source.png"

creates the path.

Then:

imwrite_unicode(src_path, bgr)

saves the original page image.

This is extremely important because both pipelines start from this same source.

So:

                ORIGINAL PAGE
                     │
             source.png
               /          \
              /            \
             ↓              ↓
           AIN             Qwen

The AIN preprocessing does not feed Qwen.

And Qwen preprocessing does not feed AIN.
